# Agentic KiCad tool reference

Generated by `tools/agentic/gen-tool-reference.py` from the tool registry; do not edit.
147 tools. Every tool also takes `project` (a project folder; default: the current one).

## Projects, files, history and server

### `batch`

Run several changing calls as one: each {tool, arguments} runs in order, then the documents are saved once and the whole batch is one undo step. If any call fails, none of the batch's changes are kept. Use it for many small edits on a large board or schematic.
